# AutoMarket API Usage Guide

This documentation explains how to use the AutoMarket backend endpoints. It is designed to be simple and easy to understand.

**Example:** The Base URL is:
"https://automarket-api-dbb4eddhhjaqchbv.centralus-01.azurewebsites.net"

### Interactive Documentation (Swagger)
You can also use the interactive documentation automatically generated by the backend. It allows you to test the endpoints directly from your browser.
- **URL:** `https://automarket-api-dbb4eddhhjaqchbv.centralus-01.azurewebsites.net/docs`


## 2. Users

### Register New User
Creates a new account in the system.

- **Method:** `POST`
- **URL:** `/users/`
- **Format:** JSON

**Data Example (Body):**
```json
{
  "email": "user@example.com",
  "password": "password123"
}
```

### Login
Verifies your credentials to enter.

- **Method:** `POST`
- **URL:** `/users/login`
- **Format:** JSON

**Data Example (Body):**
```json
{
  "email": "user@example.com",
  "password": "password123"
}
```
**Successful Response:** You will receive the user data, including their `id`. Save this ID, you will need it to publish vehicles!

## 3. Vehicles

### View All Vehicles
Gets a list of all available cars.

- **Method:** `GET`
- **URL:** `/vehiculos/`
- **Optional Parameters:** `?skip=0&limit=20` (for pagination)

### View Specific Vehicle
Gets details of a single car using its ID.

- **Method:** `GET`
- **URL:** `/vehiculos/{id}`
  - Replace `{id}` with the vehicle number (e.g. `/vehiculos/5`)

### Publish a Vehicle (Create)
Uploads a new car. **IMPORTANT:** This endpoint requires uploading an image, so it uses `multipart/form-data`, NOT JSON.

- **Method:** `POST`
- **URL:** `/vehiculos/`
- **Format:** Multipart Form Data

**Required Fields (Form Fields):**
- `marca`: (Text) e.g. "Toyota"
- `modelo`: (Text) e.g. "Corolla"
- `anio`: (Number) e.g. 2020
- `precio`: (Number) e.g. 250000
- `kilometraje`: (Number) e.g. 50000
- `descripcion`: (Text) e.g. "Excellent condition, single owner"
- `tipo`: (Text) Options: "Sedán", "Hatchback", "SUV", "Camioneta", "Coupé", "Otro"
- `transmision`: (Text) Options: "Automática", "Manual"
- `estado`: (Text) Options: "Nuevo", "Usado"
- `owner_id`: (Number) The ID of the user selling it (obtained from Login).
- `file`: (File) The vehicle image.

### Edit a Vehicle
Updates data of an existing car.

- **Method:** `PUT`
- **URL:** `/vehiculos/{id}`
- **Format:** JSON

**Data Example (Body):**
```json
{
  "marca": "Toyota",
  "modelo": "Corolla",
  "anio": 2020,
  "precio": 245000,
  "kilometraje": 55000,
  "descripcion": "Price reduced for quick sale",
  "tipo": "Sedán",
  "transmision": "Automática",
  "estado": "Usado"
}
```

### Delete a Vehicle
Removes a car from the system.

- **Method:** `DELETE`
- **URL:** `/vehiculos/{id}`

### Search Vehicles
Searches for cars by brand or model.

- **Method:** `GET`
- **URL:** `/vehiculos/search/?query=Toyota`
  - Replace `Toyota` with what you want to search for.
